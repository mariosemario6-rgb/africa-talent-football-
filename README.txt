AFRICA TALENT FOOTBALL — V2 PROFESSIONNELLE
=============================================

Cette version comprend :
- Menu mobile ☰ corrigé et accessible.
- Navigation responsive sur toutes les pages.
- 195 pays disponibles dans le formulaire d'inscription.
- Inscription internationale (joueur, club, agent, scout).
- Page de connexion préparée.
- Bouton de partage de la plateforme.
- Préparation pour un domaine professionnel www...
- Interface structurée pour une future authentification/base de données.

IMPORTANT — COMPTES ET CLÉS
----------------------------
Ce projet est un site statique compatible GitHub Pages.
Il ne contient volontairement AUCUN mot de passe réel, token, clé API ou secret.

Pour la production, il faut connecter :
1. un service d'authentification sécurisé ;
2. une base de données ;
3. le stockage des photos/documents/vidéos ;
4. des règles d'accès pour joueurs, clubs, agents et scouts ;
5. une politique de confidentialité et des règles spécifiques pour les mineurs.

NE PAS mettre de clé secrète dans app.js, HTML ou CSS.

DOMAINE PERSONNALISÉ
--------------------
Après achat d'un domaine, exemple :
www.africatalentfootball.com

Configurer ensuite le domaine personnalisé dans GitHub Pages et les enregistrements DNS chez le registrar.

PROPOSITION DE PROCHAINE ÉTAPE
------------------------------
Backend de production : authentification + profils privés/publics + base joueurs + recherche multicritère + upload média + messagerie sécurisée + espace administrateur.

Pour un lancement international, il faut tester la plateforme sur Android, iPhone et ordinateur avant communication massive.
