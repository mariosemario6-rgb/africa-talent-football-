AFRICA TALENT FOOTBALL — V3 PROFESSIONAL
=============================================

Cette version corrige notamment le menu mobile qui pouvait recevoir plusieurs gestionnaires
de clic et ne pas afficher correctement le bouton ☰ sur petits écrans.

Améliorations:
- navigation professionnelle unifiée sur toutes les pages
- menu mobile fonctionnel avec aria-expanded, fermeture au clic extérieur et Escape
- page Clubs & marchés mondiaux
- navigation Talents / Clubs / Réseau / Solutions / À propos / inscription
- responsive mobile/tablette/ordinateur
- robots.txt + sitemap.xml
- conservation du profil joueur et des éléments existants

IMPORTANT:
Cette version reste un site statique GitHub Pages.
Les comptes réels, mots de passe, messagerie, recherche serveur et notifications nécessitent
un backend sécurisé. Ne pas considérer la démo localStorage comme un système de production.
